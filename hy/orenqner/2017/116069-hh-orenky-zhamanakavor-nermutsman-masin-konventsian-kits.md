# ՀՀ ՕՐԵՆՔԸ «ԺԱՄԱՆԱԿԱՎՈՐ ՆԵՐՄՈՒԾՄԱՆ ՄԱՍԻՆ» ԿՈՆՎԵՆՑԻԱՆ (ԿԻՑ ՀԱՅՏԱՐԱՐՈՒԹՅԱՄԲ) ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

**ՕՐԵՆՔԸ**
