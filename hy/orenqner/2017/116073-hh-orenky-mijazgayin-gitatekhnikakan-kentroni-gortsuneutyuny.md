# ՀՀ ՕՐԵՆՔԸ «ՄԻՋԱԶԳԱՅԻՆ ԳԻՏԱՏԵԽՆԻԿԱԿԱՆ ԿԵՆՏՐՈՆԻ ԳՈՐԾՈՒՆԵՈՒԹՅՈՒՆԸ ՇԱՐՈՒՆԱԿԵԼՈՒ ՄԱՍԻՆ» ՀԱՄԱՁԱՅՆԱԳԻՐԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

**ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ**

**ՕՐԵՆՔԸ**

Ընդունված է 2017 թվականի սեպտեմբերի 12-ին

**«ՄԻՋԱԶԳԱՅԻՆ ԳԻՏԱՏԵԽՆԻԿԱԿԱՆ ԿԵՆՏՐՈՆԻ ԳՈՐԾՈՒՆԵՈՒԹՅՈՒՆԸ ՇԱՐՈՒՆԱԿԵԼՈՒ ՄԱՍԻՆ» ՀԱՄԱՁԱՅՆԱԳԻՐԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ**

## Հոդված 1. Վավերացնել 2015 թվականի դեկտեմբերի 9-ին Աստանայում ստորագրված՝ «Միջազգային գիտատեխնիկական կենտրոնի գործունեությունը շարունակելու մասին» համաձայնագիրը:

## Հոդված 2. Սույն օրենքն ուժի մեջ է մտնում պաշտոնական հրապարակմանը հաջորդող օրվանից։
