# ՀՀ ՕՐԵՆՔԸ «ՏԻԵԶԵՐԱԿԱՆ ՕԲՅԵԿՏՆԵՐԻ ԿՈՂՄԻՑ ՀԱՍՑՎԱԾ ՎՆԱՍԻ ՀԱՄԱՐ ՄԻՋԱԶԳԱՅԻՆ ՊԱՏԱՍԽԱՆԱՏՎՈՒԹՅԱՆ ՄԱՍԻՆ» ԿՈՆՎԵՆՑԻԱՆ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

**ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ**

**ՕՐԵՆՔԸ**

Ընդունված է 2017 թվականի հոկտեմբերի 27-ին

**«ՏԻԵԶԵՐԱԿԱՆ ՕԲՅԵԿՏՆԵՐԻ ԿՈՂՄԻՑ ՀԱՍՑՎԱԾ ՎՆԱՍԻ ՀԱՄԱՐ ՄԻՋԱԶԳԱՅԻՆ ՊԱՏԱՍԽԱՆԱՏՎՈՒԹՅԱՆ ՄԱՍԻՆ» ԿՈՆՎԵՆՑԻԱՆ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ**

## Հոդված 1. Վավերացնել 1972 թվականի մարտի 29-ին Լոնդոնում, Մոսկվայում և Վաշինգտոնում ստորագրված՝ «Տիեզերական օբյեկտների կողմից հասցված վնասի համար միջազգային պատասխանատվության մասին» կոնվենցիան:

## Հոդված 2. Սույն օրենքն ուժի մեջ է մտնում պաշտոնական հրապարակմանը հաջորդող օրվանից։
