# ՀՀ ՕՐԵՆՔԸ «ԵՎՐԱՍԻԱԿԱՆ ՏՆՏԵՍԱԿԱՆ ՄԻՈՒԹՅԱՆ ՄԱՔՍԱՅԻՆ ՕՐԵՆՍԳՐՔԻ ՄԱՍԻՆ» ՊԱՅՄԱՆԱԳԻՐԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

**ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ**

**ՕՐԵՆՔԸ**

Ընդունված է 2017 թվականի դեկտեմբերի 6-ին

**«ԵՎՐԱՍԻԱԿԱՆ ՏՆՏԵՍԱԿԱՆ ՄԻՈՒԹՅԱՆ ՄԱՔՍԱՅԻՆ ՕՐԵՆՍԳՐՔԻ ՄԱՍԻՆ» ՊԱՅՄԱՆԱԳԻՐԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ**

## Հոդված 1. Վավերացնել 2017 թվականի ապրիլի 11-ին Մոսկվայում ստորագրված՝ «Եվրասիական տնտեսական միության մաքսային օրենսգրքի մասին» պայմանագիրը:

## Հոդված 2. Սույն օրենքն ուժի մեջ է մտնում պաշտոնական հրապարակմանը հաջորդող օրվանից։
