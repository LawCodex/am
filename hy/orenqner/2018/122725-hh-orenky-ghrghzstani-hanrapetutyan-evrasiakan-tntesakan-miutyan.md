# ՀՀ ՕՐԵՆՔԸ «ՂՐՂԶՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ` «ԵՎՐԱՍԻԱԿԱՆ ՏՆՏԵՍԱԿԱՆ ՄԻՈՒԹՅԱՆ ՄԱՍԻՆ» 2014 ԹՎԱԿԱՆԻ ՄԱՅԻՍԻ 29-Ի ՊԱՅՄԱՆԱԳՐԻՆ ՄԻԱՆԱԼՈՒ ՎԵՐԱԲԵՐՅԱԼ» 2014 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 23-ԻՆ ՍՏՈՐԱԳՐՎԱԾ ՊԱՅՄԱՆԱԳՐԻ ԱՌԱՆՁԻՆ ԴՐՈՒՅԹՆԵՐԻ ԿԻՐԱՌՄԱՆ ՎԵՐԱԲԵՐՅԱԼ» ԱՐՁԱՆԱԳՐՈՒԹՅՈՒՆԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

**ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ**

**ՕՐԵՆՔԸ**

Ընդունված է 2018 թվականի մայիսի 23-ին

«ՂՐՂԶՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ` «ԵՎՐԱՍԻԱԿԱՆ ՏՆՏԵՍԱԿԱՆ ՄԻՈՒԹՅԱՆ ՄԱՍԻՆ» 2014 ԹՎԱԿԱՆԻ ՄԱՅԻՍԻ 29-Ի ՊԱՅՄԱՆԱԳՐԻՆ ՄԻԱՆԱԼՈՒ ՎԵՐԱԲԵՐՅԱԼ» 2014 ԹՎԱԿԱՆԻ ԴԵԿՏԵՄԲԵՐԻ 23-ԻՆ ՍՏՈՐԱԳՐՎԱԾ ՊԱՅՄԱՆԱԳՐԻ ԱՌԱՆՁԻՆ ԴՐՈՒՅԹՆԵՐԻ ԿԻՐԱՌՄԱՆ ՎԵՐԱԲԵՐՅԱԼ» ԱՐՁԱՆԱԳՐՈՒԹՅՈՒՆԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

Հոդված 1. Վավերացնել 2017 թվականի ապրիլի 11-ին Մոսկվայում ստորագրված՝ «Ղրղզստանի Հանրապետության՝ «Եվրասիական տնտեսական միության մասին» 2014 թվականի մայիսի 29-ի պայմանագրին միանալու վերաբերյալ» 2014 թվականի դեկտեմբերի 23-ին ստորագրված պայմանագրի առանձին դրույթների կիրառման վերաբերյալ» արձանագրությունը:

## Հոդված 2. Սույն օրենքն ուժի մեջ է մտնում պաշտոնական հրապարակմանը հաջորդող օրվանից։
