# ՀՀ ՕՐԵՆՔԸ «1997 ԹՎԱԿԱՆԻ ՍԵՊՏԵՄԲԵՐԻ 20-Ի` ՀՀ ԿԱՌԱՎԱՐՈՒԹՅԱՆ ԵՎ ԲԵԼԱՌՈՒՍԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ ՄԻՋԵՎ ՄԻՋԱԶԳԱՅԻՆ ԱՎՏՈՄՈԲԻԼԱՅԻՆ ՀԱՂՈՐԴԱԿՑՈՒԹՅԱՆ ՄԱՍԻՆ» ՀԱՄԱՁԱՅՆԱԳՐՈՒՄ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐ ԵՎ ԼՐԱՑՈՒՄՆԵՐ ԿԱՏԱՐԵԼՈՒ ՄԱՍԻՆ» ԱՐՁԱՆԱԳՐՈՒԹՅՈՒՆԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

**ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ**

**ՕՐԵՆՔԸ**

Ընդունված է 2018 թվականի սեպտեմբերի 11-ին

«1997 ԹՎԱԿԱՆԻ ՍԵՊՏԵՄԲԵՐԻ 20-Ի` ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ ԵՎ ԲԵԼԱՌՈՒՍԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԿԱՌԱՎԱՐՈՒԹՅԱՆ ՄԻՋԵՎ ՄԻՋԱԶԳԱՅԻՆ ԱՎՏՈՄՈԲԻԼԱՅԻՆ ՀԱՂՈՐԴԱԿՑՈՒԹՅԱՆ ՄԱՍԻՆ» ՀԱՄԱՁԱՅՆԱԳՐՈՒՄ ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐ ԵՎ ԼՐԱՑՈՒՄՆԵՐ ԿԱՏԱՐԵԼՈՒ ՄԱՍԻՆ» ԱՐՁԱՆԱԳՐՈՒԹՅՈՒՆԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

Հոդված 1. Վավերացնել 2017 թվականի հունիսի 29-ին ստորագրված՝ «1997 թվականի սեպտեմբերի 20-ի` Հայաստանի Հանրապետության կառավարության և Բելառուսի Հանրապետության կառավարության միջև միջազգային ավտոմոբիլային հաղորդակցության մասին» համաձայնագրում փոփոխություններ և լրացումներ կատարելու մասին» արձանագրությունը:

## Հոդված 2. Սույն օրենքն ուժի մեջ է մտնում պաշտոնական հրապարակմանը հաջորդող օրվանից։
