# ՀՀ ՕՐԵՆՔԸ ՀՀ-Ի ԵՎ ՎԵՐԱԿԱՆԳՆՄԱՆ ՎԱՐԿԵՐԻ ԲԱՆԿԻ ՄԻՋԵՎ «ՔԱՂԱՔԱԿԱՆՈՒԹՅԱՆ ՎՐԱ ՀԻՄՆՎԱԾ ՎԱՐԿ - ՇՐՋԱԿԱ ՄԻՋԱՎԱՅՐԻ ՊԱՀՊԱՆՈՒԹՅՈՒՆ - BMZ 3010 00 579, ՎԱՐԿ N 29426» ՎԱՐԿԱՅԻՆ ՀԱՄԱՁԱՅՆԱԳԻՐԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ

**ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ**

**ՕՐԵՆՔԸ**

Ընդունված է 2019 թվականի դեկտեմբերի 12-ին

**ՀԱՅԱՍՏԱՆԻ ՀԱՆՐԱՊԵՏՈՒԹՅԱՆ ԵՎ ՎԵՐԱԿԱՆԳՆՄԱՆ ՎԱՐԿԵՐԻ ԲԱՆԿԻ ՄԻՋԵՎ «ՔԱՂԱՔԱԿԱՆՈՒԹՅԱՆ ՎՐԱ ՀԻՄՆՎԱԾ ՎԱՐԿ - ՇՐՋԱԿԱ ՄԻՋԱՎԱՅՐԻ ՊԱՀՊԱՆՈՒԹՅՈՒՆ - BMZ 3010 00 579, ՎԱՐԿ N 29426» ՎԱՐԿԱՅԻՆ ՀԱՄԱՁԱՅՆԱԳԻՐԸ ՎԱՎԵՐԱՑՆԵԼՈՒ ՄԱՍԻՆ**

## Հոդված 1. Վավերացնել 2019 թվականի նոյեմբերի 11-ին ստորագրված` Հայաստանի Հանրապետության և Վերականգնման վարկերի բանկի միջև «Քաղաքականության վրա հիմնված վարկ - Շրջակա միջավայրի պահպանություն - BMZ 3010 00 579, վարկ N 29426» վարկային համաձայնագիրը:
